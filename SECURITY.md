# Security policy

## Private reporting channel required

Before accepting security reports, maintainers must configure and publish a
private reporting channel here. No private reporting contact is configured in
this repository yet. Do not place vulnerability details, credentials, or
sensitive research data in public issues, pull requests, discussions, or commit
messages.

Until a channel is configured, report only non-sensitive, high-level concerns
through the repository owner without including exploit details. Maintainers must
acknowledge a report, agree on a private channel, and coordinate disclosure
before requesting reproduction material.

## Scope and limits

This source-only developer alpha has no supported hosted service, production
remote deployment, provider integration, or security response SLA. Synthetic
fixtures and local development credentials are not production security
boundaries. Do not test against systems, accounts, providers, or data that you
do not own and have explicit permission to assess.

Security reports should include affected revision, a minimal safe reproduction,
impact, and any mitigation already attempted. Never include secrets or private
research inputs.
