# Changelog

Tessera remains a developer alpha. Git history records source changes; this page
does not create release tags, a supported binary release or compatibility promises.

## Unreleased

- Local control and desktop research records, separate approval/admission and
  worker execution, artifact quarantine/custody and governed agent interfaces.
- Explicit schema migrations and SQLite/project-object backups; restored history
  remains permanently held and does not fence original services or external jobs.
- Current user, operator and developer guidance starts at [docs](docs/README.md).
  See [capabilities and limits](docs/implemented-capabilities.md) before evaluation
  and the [maintainer checklist](docs/release-checklist.md) before release.
